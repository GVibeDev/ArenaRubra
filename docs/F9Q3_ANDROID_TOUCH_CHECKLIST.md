# F9Q3 — Checklist Android / touch

Questa checklist accompagna la candidata e non costituisce una dichiarazione di validazione definitiva su dispositivo.

## Eseguito nel browser con layout compatto

- [x] La UI mostra l’avviso orientamento senza bloccare l’uso.
- [x] MAP2 e MAP3 vengono adattate alla viewport con il comando Fit.
- [x] HUD compatta mostra il partecipante attivo e i valori G1–G4.
- [x] Le celle restano elementi interattivi accessibili.
- [x] Il menu mobile non apre quattro pannelli giocatore simultaneamente.
- [x] Pan, zoom, Fit e pannelli Mano/Azioni/Log/Stats restano disponibili.
- [x] L’editor usa pointer events per pan e selezione.
- [x] I controlli editor sono impilati nel layout responsive.

## Da ripetere su APK/dispositivo reale

- [ ] Avvio a freddo su Android.
- [ ] Rotazione portrait/landscape durante MAP2 e MAP3.
- [ ] Pinch zoom e pan prolungato su 229/265 celle.
- [ ] Pressione lunga, tap ravvicinati e selezione celle al bordo.
- [ ] Editor: pan, zoom, modifica, annulla/ripeti e tastiera virtuale.
- [ ] Import JSON dal selettore file Android.
- [ ] Export JSON nella cartella Download.
- [ ] Resume dopo sospensione e chiusura dell’app.
- [ ] Partita tutti-bot estesa con schermo spento/riattivato.
- [ ] Controllo memoria e fluidità su dispositivo di fascia bassa.

## Criterio

La candidata può essere promossa soltanto dopo il completamento della sezione su dispositivo reale e l’assenza di regressioni bloccanti.

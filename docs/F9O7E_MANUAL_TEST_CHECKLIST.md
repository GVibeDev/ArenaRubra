# F9O7e — Checklist manuale Lezione 3 Agathoi

## Avvio

- [ ] Nel menu Tutorial risultano giocabili tre lezioni.
- [ ] La Lezione 3 mostra titolo e descrizione Agathoi corretti.
- [ ] All’avvio compaiono Oplita di Confine sul PS centrale e Radura Curativa adiacente.
- [ ] La Mano contiene quattro tattiche e nessuna carta Starter.

## Prima ondata

- [ ] La Mano viene aperta quando bisogna scegliere Manto di Rovi.
- [ ] Dopo la selezione della carta, la Mano si riduce e l’Oplita resta cliccabile.
- [ ] Lo status Spine 2 è visibile o leggibile nella scheda unità.
- [ ] Fine turno è raggiungibile sotto le abilità di fazione.
- [ ] La Guardia di Aurex viene distrutta dalle Spine.
- [ ] Il tutorial prosegue senza vignette sovrapposte.

## Ripresa

- [ ] Uscire dopo la prima ondata conserva il checkpoint.
- [ ] Riprendere riapre il passo Natura Vigile, non il benvenuto.
- [ ] Mano, turno, ENE, Oplita e Radura vengono ripristinati correttamente.
- [ ] Non restano targeting, selezioni o pulsanti della sessione precedente.

## Seconda ondata

- [ ] Natura Vigile può essere selezionata e applicata all’Oplita.
- [ ] Il Legionario consuma la DEF residua dell’Oplita.
- [ ] Spine e Contrattacco vengono entrambi risolti.
- [ ] Il Legionario viene distrutto.
- [ ] Gli HP dell’Oplita restano a 3.

## Terza ondata

- [ ] Bastione Ligneo può essere applicato alla Radura Curativa.
- [ ] La Radura mostra 4 DEF prima dell’attacco.
- [ ] L’Artiglieria azzera la DEF ma non riduce i 4 HP della Radura.
- [ ] L’Oplita può essere selezionato senza che la Mano copra la mappa.
- [ ] L’attacco finale distrugge l’Artiglieria.
- [ ] Il PS centrale resta controllato dagli Agathoi.

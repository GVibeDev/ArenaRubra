# Arena Rubra Starter 1.0 — Glossario IT/EN

| Italiano | English | Significato / Meaning |
|---|---|---|
| ATT | ATK | Forza dell'attacco base / base attack strength. |
| DEF | DEF | Difesa consumata prima degli HP / defence spent before HP. |
| HP | HP | Salute; a zero l'unità è rimossa / health; at zero the unit is removed. |
| ENE | ENE | Risorsa pagata per carte, abilità e recupero / resource spent on cards, abilities and recovery. |
| Punto Strategico (PS) | Strategic Point (SP) | Obiettivo territoriale che fornisce controllo e reddito / territorial objective providing control and income. |
| Quartier Generale (QG) | Headquarters (HQ) | Cella-obiettivo di ogni giocatore / each player's objective cell. |
| Pressione Strategica | Strategic Pressure | Condizione di vittoria basata su centro e maggioranza PS / centre-and-majority victory track. |
| Mano | Hand | Carte disponibili al giocatore / cards available to the player. |
| Deck / Mazzo | Deck | Pila di pesca regolamentare / regulation draw pile. |
| Scarti | Discard pile | Carte risolte, distrutte o scartate / resolved, destroyed or discarded cards. |
| Riserva Starter | Starter reserve | Tre carte di base riutilizzabili fuori dal deck / three reusable basic cards outside the deck. |
| Missione | Mission | Carta pubblica con obiettivo e ricompensa / public card with objective and reward. |
| Tattica | Tactic | Carta che produce un effetto senza diventare miniatura / effect card that does not become a unit token. |
| Fanteria | Infantry | Unità mobile che normalmente agisce dopo il movimento / mobile unit that normally acts after moving. |
| Veicolo | Vehicle | Unità mobile con distanza legata al ritmo e alla mappa / mobile unit whose range depends on pace and map. |
| Struttura | Structure | Unità immobile che può estendere la rete di sbarco / immobile unit that can extend deployment. |
| Comandante | Commander | Carta unica scelta nel setup / unique card selected during setup. |
| Pivot | Pivot | Unità caratterizzante soggetta a cap dedicato / signature unit with a dedicated cap. |
| Schieramento | Deployment | Ingresso legale di una carta unità sulla mappa / legal placement of a unit card on the map. |
| Stato | Status | Effetto temporaneo o persistente applicato a unità/celle/giocatori / temporary or persistent effect. |
| Bot Advanced | Advanced bot | Massimo livello AI ufficiale Starter / highest official Starter AI level. |
| Bot Expert | Expert bot | Funzione DEV/sperimentale, non Distribution / DEV/experimental feature, not Distribution. |

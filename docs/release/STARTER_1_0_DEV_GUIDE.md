# Arena Rubra Starter 1.0 — DEV Guide

## Product profiles

The checkout defaults to `dev`. A staged public build must use the `distribution` profile. Distribution excludes editors, calibration labs and Expert AI modules before they execute. Do not claim Expert as an official Starter feature; Advanced is the public ceiling.

## Canonical sources

- Content freeze: `data/starter_1_0_manifest.json` generated by `tools/generate_starter_1_0_manifest.js`.
- Asset inventory: `data/required_assets.json` generated by `tools/generate_visual_asset_inventory.js`.
- Statistics: `docs/release/STARTER_1_0_STATISTICS_REGISTER.md` generated by `tools/generate_starter_statistics_register.js`.
- Runtime rules: `src/rules/victory_lifecycle.js`, `src/rules/pressure_victory.js`, `src/board.js`, `src/constants.js`, `src/deck.js` and `src/turns.js`.
- Visible build metadata: `src/build_info.js`. Do not duplicate version labels in UI code.

## Freeze workflow

Regenerate a file only with its declared generator, then run that generator with `--check` where supported. A changed content catalog must intentionally change the manifest hash and be reviewed as a post-freeze content change. Required assets must pass path, byte-size and SHA-256 verification; optional ornamentation may use documented fallback.

Run the JavaScript syntax check, locale parity/content gates, manifest gate, required-asset gate, profile/staging gates and the milestone-specific browser tests before producing an artifact. Build staging must happen from an intentional source state; a clean-checkout packaging proof is an RC requirement, not a documentation assumption.

## Release boundaries

Starter 1.0 targets Desktop/Web. Android packaging is not a release requirement. From S2-RC onward, changes are bugfix-only. Never label a build validated without the required human validation; automated gates may report PASS but do not replace that approval.

## Licensing

Source files are covered by MPL 2.0 unless stated otherwise. Assets, art, logos, faction names, setting, lore, card text, audio, visual identity, generated images, prompts and design documents are reserved by their owner as stated in `Asset_License`. Preserve both notices in every distribution.

# Arena Rubra — F9U2b Checklist manuale

Build: **C2-STABLE-1-F9U2b-APK-M4c**  
Baseline: **C2-STABLE-1-F9U2a-APK-M4c**

## 1. Avvio e metadati

- [ ] L’app si avvia senza errori.
- [ ] La versione visibile è `C2-STABLE-1-F9U2b-APK-M4c`.
- [ ] Dal menu principale si raggiungono Card Editor e Map Editor.

## 2. Card Editor — toolbar

- [ ] Nuova, Salva, Duplica ed Elimina sono ordinati e immediatamente visibili.
- [ ] “Strumenti dati” si apre e si chiude correttamente.
- [ ] Calibra renderer apre il laboratorio previsto.
- [ ] Copia JSON carta copia la carta corrente.
- [ ] Copia libreria copia la libreria custom.
- [ ] Deck Builder, Pool carte e Menu navigano correttamente.

## 3. Card Editor — modulo e anteprima

- [ ] Identità, statistiche e abilità risultano leggibili e ben separate.
- [ ] La sezione Illustrazione e allineamento si apre e mantiene tutti i controlli.
- [ ] Cambiando nome, fazione, tipo, ENE, HP, DEF o ATT l’anteprima si aggiorna.
- [ ] Passiva e attiva vengono salvate e mostrate nell’anteprima.
- [ ] La validazione del budget continua a segnalare correttamente errori e warning.
- [ ] L’anteprima resta affiancata durante lo scorrimento su desktop.

## 4. Card Editor — libreria e scambio dati

- [ ] La libreria custom mostra le carte salvate.
- [ ] Filtri e selezione della libreria funzionano.
- [ ] Caricamento, duplicazione ed eliminazione non producono errori.
- [ ] Import e export JSON continuano a funzionare.
- [ ] Nessuna funzione preesistente è scomparsa.

## 5. Map Editor — toolbar

- [ ] Nuova, Salva e Importa sono ordinati nella barra superiore.
- [ ] Il gruppo Export mostra JSON leggero e JSON portatile.
- [ ] Annulla e Ripeti aggiornano correttamente la mappa.
- [ ] Adatta ricentra la mappa.
- [ ] Menu torna correttamente al menu principale.

## 6. Map Editor — barra live

- [ ] Stato di validazione, nome, giocatori, celle, QG e PS sono corretti.
- [ ] Il moltiplicatore movimento coincide con la mappa.
- [ ] Lo zoom si aggiorna durante l’uso della camera.
- [ ] Lo strumento attivo cambia immediatamente nella barra.
- [ ] Selezionando una cella, coordinate o identificativo compaiono nella barra.

## 7. Map Editor — pannello sinistro

- [ ] Proprietà generali della mappa modificabili.
- [ ] Sfondo custom caricabile e configurabile.
- [ ] Geometria e componenti restano accessibili.
- [ ] Le modifiche aggiornano canvas e barra live senza errori.

## 8. Map Editor — pannello destro

- [ ] Tutti gli strumenti di pittura/selezione sono presenti.
- [ ] Le opzioni dello strumento cambiano in base allo strumento attivo.
- [ ] Simmetria e pennello funzionano.
- [ ] Il pannello della cella selezionata mostra e salva le proprietà.
- [ ] Validazione, legenda, Match Lab ed eliminazione restano disponibili.

## 9. Salvataggio e compatibilità

- [ ] Salvare una mappa e riaprirla non perde dati.
- [ ] Importare un JSON leggero funziona.
- [ ] Importare un JSON portatile funziona.
- [ ] Una mappa precedente alla F9U2b si apre correttamente.
- [ ] Una carta custom precedente alla F9U2b si apre correttamente.

## 10. Regressioni essenziali

- [ ] Pool carte invariato e funzionante.
- [ ] Deck Builder mostra i 50 deck ufficiali.
- [ ] Setup permette la selezione dei deck.
- [ ] Una partita si avvia normalmente.
- [ ] HUD, Inspector, mano e barre PS/unità restano corretti.
- [ ] Debug, Log, Statistiche e Telemetria si aprono.
- [ ] Lo schema telemetrico resta `F9Q3e1-2`.

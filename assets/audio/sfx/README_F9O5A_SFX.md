# Arena Rubra F9O5a — SFX

F9O5a usa effetti sonori sintetici Web Audio per consentire il test senza asset binari.
La cartella è predisposta per campioni futuri:

- attack.ogg / attack.mp3
- impact.ogg / impact.mp3
- destruction.ogg / destruction.mp3
- ability.ogg / ability.mp3

I campioni futuri dovranno essere brevi, normalizzati e senza silenzio iniziale. Il runtime
F9O5a non li carica ancora automaticamente: il registry è soltanto predisposto per il gate
successivo, dopo la valutazione su Android.

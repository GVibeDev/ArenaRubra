# Arena Rubra – Token graphics slots F9M2

La modalità token grafici è OFF di default. Se viene attivata dal Layout Calibration Lab, il renderer prova a usare questi asset `.webp`.
Se un file manca, il token CSS/SVG resta visibile come fallback.

Per ogni fazione ufficiale:

- `infantry.webp`
- `vehicle.webp`
- `structure.webp`
- `commander.webp`
- `pivot.webp`
- `qg.webp`

Cartelle previste:

- `nexus/`
- `exordium/`
- `liberti/`
- `agathoi/`
- `fabeot/`
- `custom/` (senza `qg.webp` obbligatorio)

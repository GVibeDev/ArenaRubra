# F9O4 — Dorsi carta di fazione

Inserire il dorso nella cartella radice della fazione, accanto alle sottocartelle `units/` e `tactics/` del deploy FULL.

Percorsi preferiti:

- `nexus/nexback.webp`
- `exordium/exoback.webp`
- `liberti/libback.webp`
- `agathoi/agaback.webp`
- `fabeot/fabback.webp`

Il resolver prova, nell'ordine, `.webp`, `.png`, `.jpg`, `.jpeg`, poi il vecchio dorso in `assets/cards/frames/`. Se nessun file è presente usa il fallback procedurale.

Le varianti numeriche (`nexback2.webp`, ecc.) sono riservate a una milestone futura e non vengono risolte in F9O4.
